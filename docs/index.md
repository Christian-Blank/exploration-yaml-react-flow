## System Overview

The Schema-First Knowledge Graph System is built around a schema-first approach where YAML-defined schemas are the single source of truth. The system centers around node-based entities representing processes and documents, enabling easy human readability, automated type generation, and developer-friendly workflows.

Key features:
- Schema-first design with OpenAPI 3.1 schemas as the single source of truth
- Automatic type generation for Python and TypeScript
- Local schema server for easy access to schemas
- CLI tools for working with schemas and nodes
- Web UI for interactive visualization and editing of nodes
